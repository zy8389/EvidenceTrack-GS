# GeoTrack-GS × Diffusion：方案复审与理论说明

版本：Research v2；日期：2026 年 9 月 6 日。本文用于内部研究推进，英文主稿见 paper/main_v2.pdf。

## 一、此次交付的边界

本轮沿用已上传的 Phase 2.1 微修复包，以及 CPy255/GeoTrack-GS 的固定提交 81ada6a32c918591ae7c7a0279dc6ca7a8018e2f。不是重新发明一个与现有工程无关的选题，也没有进入 Adapter、生成器微调、可学习可靠性网络或后验融合。新增加的 checkpoint、calibration、metric 工具属于工程一致性修复，不是新增研究模型。

论文暂定题目为 EvidenceTrack-GS: Identity-Controlled Geometry Diagnostics for Diffusion-Assisted Sparse-View Gaussian Splatting。中文可表述为“面向扩散辅助稀疏视角高斯重建的轨迹身份控制与几何证据诊断”。名称是这轮写作的暂名，不宣称此前已发表。

当前能成立的是：给出清楚的 source-only 几何构建、可执行的受控实验、可证的局部性质，以及防止伪收益的身份诊断。当前不能成立的是：已经证明 Difix 为真实场景增加正确几何、已经达到 SOTA、已经消除幻觉，或已经具有足以保证 CVPR 录用的创新性。

## 二、核心逻辑重新梳理

研究链条应为：真实源图像建立可信对应关系；对应关系构成局部几何约束；冻结扩散模型提供先验增强的候选图像；通过严格对照检验候选图像是否真正保留源轨迹身份、是否优于纯投影位置、是否提高最终重建。当前工程实现了这一链条的实验条件，但诊断结果没有反馈到训练中。因此它是“受控基线＋证据诊断”，不是已经实现的“证据驱动闭环模型”。

最重要的反例是：如果真实投影本来就在正确位置附近，任何仅在投影附近搜索的匹配器都可能得到不差的误差。即使打乱 query，或者把匹配器换成接近均匀的权重，soft-argmax 仍会停在窗口中心附近。只报告匹配精度，不能证明 Track identity 被使用。

另一个反例是：Difix 图像视觉上更清晰，DINO 匹配也更稳定，但其位置误差依旧大于原本的 ProjectionOnly。这最多支持外观或特征稳定化，不支持“新增几何证据”。正确的结果解释要同时看增强收益、几何收益、身份收益和匹配失败率。

第三个反例是：B 从 10k 训练到 12k，比 A0 的 10k 更好，但 A1 同样继续训练到 12k 也能达到相同结果。此时提升不能归因于扩散。即使B优于A1，也还可能只是额外pseudo-view监督的作用。因此第一轮严格采用A0→A1、A0→SelfRender、A0→B的同源checkpoint分叉，分别估计通用pseudo监督、Difix target替换和B总分支效应。

## 三、与近期工作的关系

Difix3D+ 已经展示单步扩散增强重建的路线，使用它的官方冻结模型不是新的扩散模型贡献。GIFSplat 已将冻结生成先验用于迭代式前馈高斯更新；我们是带给定相机的逐场景梯度优化，任务和计算方式不同，不应该直接把不同设定混排为公平排名。HAD 已利用预训练 NVS 模型估计幻觉分数，并对生成像素进行选择性蒸馏；因此一个像素 mask 不能直接声称是全新贡献。Track4DGen 已在动态生成中加入 tracker-derived feature priors；“我们静态、它动态”也不足以单独支撑创新性。

更有辨识度的研究问题是：生成先验的收益究竟是否依赖正确的源轨迹身份，并且是否在控制投影邻域与训练量之后仍有几何价值。这需要实验证据，而不是把若干现成模型并列组合。核心文献均已核对其作者原始摘要或官方仓库，具体条目见 paper/references.bib；未核对的前期文献名称没有被强行写进结论。

## 四、source-only 到底意味着什么

本稿的 strict protocol 表示：Track membership、Track ID、三角化锚点、初始化点云颜色与置信度，仅由选出的 source RGB 构建；允许使用已经给定的 source intrinsics/extrinsics。它不表示“用三张图重新估计了所有相机位姿”。如果相机位姿来自 full-scene SfM，要对所有方法明确披露这一给定条件。

现有 strict builder 使用 source-source SIFT mutual-ratio matching 和给定位姿的 epipolar filtering 来构建身份，不打开 full points3D.bin 读取 track membership。Legacy 路径可以继续存在，但不得混入 strict 主结果。HDF5 中的 source 子集在附加 held-out 对应标签之前冻结。

为了评估，builder 还会做 source-to-heldout matching，要求多源投票后附加 held-out 观测。这些是 SIFT 对应“代理标签”，不是独立几何真值。重复纹理、遮挡和错误多源匹配仍可能产生一致但错误的标签。需要人工核查和 DTU／合成真几何来补证。

数据隔离的可证性质是：若所有训练输入都是 S、C、W、Z 的函数，且更新、停止、阈值选择均不读取 E，那么改变 held-out RGB E 不会改变数学上的训练轨迹。CPU 测试只证明了部分数据结构和逻辑。真实服务器上仍要进行删除、替换、打乱 held-out 信息后的训练等价测试。不要把“没有进入 loss”偷换成“任何代码都没有打开 held-out 文件”。

## 五、几何理论能证明什么

### 5.1 三角化与局部信息

给定世界到相机变换 y=RX+t，投影为 (fx·x/z+cx, fy·y/z+cy)。其 Jacobian 为 [[fx/z,0,-fx·x/z²],[0,fy/z,-fy·y/z²]]R。单个视角的 Jacobian 秩为 2，其零空间沿观察射线，所以单视角无法在这个局部模型中约束沿射线的深度。

多视角加权信息矩阵 H=ΣwJᵀJ。对任意扰动 v，有 vᵀHv=Σw‖Jv‖²。当各源视角射线零空间只有零向量的交集时，H 正定。它解释了为什么非退化多视角对应能够对局部三维点扰动产生恢复梯度。

这不是联合 3DGS 优化的全局收敛证明。错误匹配、近共线相机、密度/不透明度自由度、关联切换、动态遮挡都会突破这一局部假设。论文明确写的是 Gauss–Newton 局部可观性，不是“Track 保证任何场景几何正确”。

### 5.2 无量纲 quality

局部协方差采用相对阻尼：Σ=(H/h+ηI)⁻¹/h，h=tr(H)/3，η=10⁻⁸。局部条件数过差时拒绝该轨迹。source-only scene scale 采用源相机正的两两 baseline 中位数 s。

定义 ν=√tr(Σ)/s；质量 q=min(1,log(1+m)/log7)·exp(-e/2)/(1+ν)。其中 m 是 source track 长度，e 是源图原始像素尺度的平均重投影误差。ν 无量纲，而单独的 √tr(Σ) 有世界长度单位。

在 X′=aQX+b 的相似变换下，给定相机同样变换，J′=JQᵀ/a，H′=QHQᵀ/a²，Σ′=a²QΣQᵀ，s′=as，因此 ν′=ν、q′=q。新的 CPU 测试覆盖 10⁻⁶、10⁻³、10、10³、10⁶ 五个尺度的局部计算，但当前修复源码依用户要求尚未运行这些测试。这里不宣称整个神经训练过程对极端尺度逐位相同；正深度阈值、三角化停止条件和浮点精度仍有适用范围。

### 5.3 Loss 必须作用于当前 Gaussian

固定三角化锚点 X̄ 只是参考。如果 loss 写成 π(X̄) 与源像素的误差，X̄ 不随高斯变化，那么 loss 数值可以很小，但对当前高斯中心没有恢复作用。实现使用的是当前 μ[a(k)] 的投影，按 q·confidence 加权，使用径向 Huber：e≤δ 时为 e²/2，超过时为 δ(e−δ/2)，δ=2 像素。

几何管理器聚合活跃轨迹在各个 source camera 下的观测，而不仅是当前 RGB 抽到的那一个视角。关联采用最近锚点规则，在拓扑不变时固定，拓扑变化后重建；这不是永久一对一 Gaussian identity。需要记录关联轨迹数、唯一高斯数和碰撞率。

### 5.4 生成视图不是新传感器

令 Y=D_W(S,C,Z)，且随机量 Z 在给定 S、C、W 后与真实场景 X 条件独立，则 I(X;Y|S,C,W)=0。这是条件独立的基本推论，不包装为新发现的信息论定理。W 可以携带有用的总体先验，生成目标也可能帮助有限表达能力的模型优化；但生成 32 张图不等于采集 32 次独立真实观测。

最简单的过度自信反例：把同一个 y=x+ε 复制 n 次，真实平均误差方差仍为 σ²；错误地假设 n 个样本独立，会得到 σ²/n。当前没有把 pseudo-view 当作独立似然相乘，也没有声称实现了 Bayesian posterior fusion。

## 六、此次审查实际修正的问题

第一，协方差阻尼从带绝对 world-scale floor 的形式改为相对归一化阻尼，并拒绝退化信息矩阵。第二，图像 resize、DINO patch-grid、grid_sample、source 观测和 principal point 采用同一个 half-pixel 约定。第三，校准投影矩阵显式保留 cx、cy，不再假设 FoV 能代表全部内参。

第四，PCK 把失败预测计入分母；主比较改为共同配对样本、共同图像对角线失败惩罚，同时保留条件误差和失败率。第五，hard negative 找不到不同身份时明确标无效，不把 self fallback 当正确负例。第六，Real Target 不再称 upper bound，而称 reference diagnostic；shifted-window 的 GT-inside 筛选明确标为 oracle-conditioned secondary analysis。

第七，完整 checkpoint 保存 Adam、辅助 Gaussian 状态和随机状态，记录时点改为当前步更新之后；最终训练步不再跳过。评测调用也移动到该步更新之后，避免 PLY/checkpoint 与报告指标相差一个更新。第八，source 视角序列逐步落盘，A1、SelfRender、B的一致性不再只靠采样器名称猜测。

第九，实际 Difix 缓存要求 immutable model revision，并记录代码版本与输入/输出哈希；禁止盲目跳过旧缓存。DINOv2 通过本地固定提交加载，权重文件也需服务器记录哈希。第十，完整装配采用固定 upstream＋一次性累计补丁＋修订源码＋带结构校验的 AST 修复，遇到版本不匹配就退出，不模糊套补丁。

## 七、首轮实验与旧版本的差异

A0、A1、SelfRender、B都必须由此版本重新生成。旧 Phase 2.1 的不完整 10k checkpoint 不能直接拿来续跑。第一轮固定 full precision，densify_until_iter=10000，即三个continuation分支都冻结拓扑；同样关闭 legacy 单目深度、legacy pseudo-depth、可选旧 geometry regularizer 和 GT-DCA。这样方法正文的 source RGB＋repaired Track objective 与实现保持一致。

继续保留 32 pseudo views、interval=50、10k<t<12k，所以SelfRender与B都应有正好39次pseudo supervision并覆盖相同的32/32个视角。三个continuation共享同一个A0起点和相同真实视角序列；SelfRender与B还共享pseudo camera调用序列、权重和loss设置。若之后研究拓扑变化或旧regularizer，应作为对称新增消融，而不是只给某个分支开启。

## 八、验证结果与尚未验证的事项

历史源码快照曾完成 11 项 CPU 冒烟检查、23 项回归测试和一个三相机、单三维点、100 步 Adam 的合成恢复实验；该快照记录的平均重投影误差为 9.7511017371→0.0276231503 像素，三维锚点距离为 0.0538516481→0.0002259193。原始 JSON 与日志保留在 validation/，但当前修复源码尚未重跑，状态为 `NOT RUN`，这些历史数值不能证明当前实现通过。

这些数字不是真实重建结果。环境没有 CUDA，也没有执行实际 Difix 或 DINOv2 模型。Mock Difix 只验证随机种子与缓存调用协议；Adam fixture 只验证所实现的小模型恢复过程；AST fixture 只验证预定代码结构的改写逻辑。完整上游工程的装配、CUDA 编译、真实数据加载与端到端训练尚未在本环境完成验证。

## 九、目前的投稿判断

方案具有可执行的下一步和可检验的科学问题，但不应把目前状态描述为“已具备 Strong Accept 水平”。最危险的不是论文写得不够复杂，而是出现 B≈SelfRender（不支持冻结 Difix target 替换效应）、B≈A1（不支持冻结 Difix 分支的总收益）、正确 query≈错误 query，或者 Difix matching 仍弱于 ProjectionOnly。这些结果会直接削弱对应层级的既定叙事。即使 B 优于 SelfRender，在完成非生成增强对照前也不能把差异解释为扩散机制独有。

建议的研究推进门槛是：先通过完整服务器P0，再在开发场景完成A1/SelfRender/B三分支对照与A1/B身份诊断，随后锁定参数，在未用于调参的六个LLFF场景和独立几何数据上验证。只有跨场景证据支撑后，再决定这是一篇分析型论文，还是足以支撑后续方法创新。当前无需为了“看起来更创新”提前加Adapter。
