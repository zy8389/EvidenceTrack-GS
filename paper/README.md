# 论文文件

main_v2.tex 是当前英文扩展初稿的权威源。main_v2.pdf 是 2026-09-06 生成、早于当前修复的历史阅读快照，不能用来解释现行协议。draft_v1.tex 是保留的完整初稿快照，主要统计段落尚未补齐，不能用于报告最终结论；本轮不改写它。v1_to_v2.diff 同样是 2026-09-06 的历史派生文件，不代表当前 main_v2.tex。references.bib 为已核对的核心文献。

本稿有完整的摘要、引言、相关工作、方法、理论推导、实验方案、历史 CPU 结果及其适用边界、真实实验状态、局限及附录。历史日志早于当前修复，不能验证当前源码。它不是只有框架的模板，但也不是已有真实实验的投稿成稿。NR 意为未运行，禁止填入预期值或其他协议的文献结果。推导属于本文自洽分析，未包装为首次发现的一般数学定理。

需要更新阅读版时可运行 `bash build.sh`。编译需要 TeX Live（newtx、tikz、natbib；使用 pdflatex 与 BibTeX）。依用户要求，本轮未编译或渲染 PDF。figures/*.tex 是可直接修改的矢量示意图；figures/*.svg 是供 Visio 导入或重绘的草图版本。

该历史 PDF 采用匿名双栏工作版式，不冒称 CVPR 2027 官方模板。完成真实实验后应使用投稿年份官方 author kit，压缩正文并分离补充材料。内部研究包含仓库信息和路径，不能整体当匿名附件上传。
